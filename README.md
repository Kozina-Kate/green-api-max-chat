# GREEN-API MAX Chat

Минималистичный веб-чат на React и TypeScript для отправки и получения
текстовых сообщений в MAX через GREEN-API.

## Технологии

- React
- TypeScript
- Vite
- CSS
- Oxlint

## Локальный запуск

```bash
npm install
npm run dev
```

## Доступные команды

```bash
npm run dev      # запуск сервера разработки
npm run build    # проверка TypeScript и production-сборка
npm run lint     # статический анализ кода
npm run preview  # локальный просмотр production-сборки
```
